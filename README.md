## Getting Started

First, .env

```bash
DATABASE_URL=

AUTH_SECRET=

AUTH_GITHUB_ID=
AUTH_GITHUB_SECRET=

AUTH_GOOGLE_ID=
AUTH_GOOGLE_SECRET=

LINE_CLIENT_ID=
LINE_CLIENT_SECRET=
NEXTAUTH_URL=
AUTH_TRUST_HOST=
NEXT_PUBLIC_APP_URL=

STRIPE_SECRET_KEY=
STRIPE_WEBHOOK_SECRET=

ARCJET_KEY=
UPLOADTHING_TOKEN=

```

คำสั่งรันโปรเจค

```bash
npm  run dev

npx inngest-cli@latest dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
